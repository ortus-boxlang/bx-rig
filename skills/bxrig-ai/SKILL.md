# BxRig: AI

- Agents: `bxrig ai list`, `ai default ID`, `ai launch [ID]` (with its keys loaded), `ai shell` (pull-down terminal, `Super+``), `ai session start|list|attach|stop`.
- Keys: `bxrig secrets set KEY` (typed hidden, stored in the keyring), `secrets list|unset|run KEYS -- cmd`. `secrets` marks each key as an AI key or other. Never put keys in files, shell history or answers.json. Global export is opt-in: `secrets global on KEY`.
- Local models (llama.cpp): `bxrig ai setup --yes`, `bxrig ai models [list|recommend|pull ID --yes|use ID|test|tune --yes|remove ID --yes]`, `bxrig ai serve [start|stop]`, `bxrig ai ask TEXT`. More models: `bxrig ai discover [QUERY] [--fits]`, `bxrig ai models pull hf:OWNER/REPO --yes` (any GGUF, checked against Hugging Face's SHA-256), `--background` with `bxrig ai downloads`. Score a model here: `bxrig ai bench [ID]`. Point OpenCode or Crush at the local server: `bxrig ai link opencode|crush --yes`. On selected text: `bxrig ai text summarize|rewrite|fix|explain|translate|reply` (Super+Alt+E opens the menu). APIs: OpenAI `http://127.0.0.1:8089/v1`, Anthropic `/v1/messages`, embeddings `/v1/embeddings`; model ids are the catalog ids (`bxrig ai models`).
- BoxLang agents (bx-agents): `bxrig ai agents install --yes` (`--stable` once there is a release), `bxrig ai agents` (the projects in `~/Agents`), `bxrig ai agents new NAME`, `bxrig ai agents start|stop|status|open NAME`, `bxrig ai agents default NAME`. Anything else bx-agents does: `bxrig ai agents NAME VERB ...` runs `bxAgents VERB --projectRoot=PROJECT ...` (for example `chat`, `invoke --message=...`, `routines list`). An agent uses the local model with `profile: bxrig` in its Agent.yml. Its data is in `~/.bxagents/NAME`. Boxy, BxRig's desktop assistant: `bxrig ai agents setup --yes`; `bxrig ai agents chat` (Super+Period), `bxrig ai agents ask TEXT`, then `bxrig ai agents approve|reject THREAD` for what it waits to do; `bxrig ai agents skills [NAME] [show|approve|remove SKILL]` reviews the skills an agent saved.
- Skills for agents: `bxrig skills list|search TEXT|show REF|install REF...|installed|update|remove NAME|status`. They are stored once in `~/.agents/skills` and linked into each agent's skills folder. The hub is https://skills.boxlang.io (an API, audited skills; a skill that failed its audit cannot be installed).
